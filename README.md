# SaaS Customer Churn & Retention Analytics

An end-to-end business intelligence project built using Microsoft Power BI to analyze customer churn, retention patterns, subscription performance, and recurring revenue.

## Project Overview
This project analyzes 10,000 SaaS customer records to identify churn patterns, understand customer behavior, and evaluate subscription revenue.

## Dashboard Pages
1. Executive Overview
2. Retention Analysis
3. Customer Risk Analysis
4. Revenue Analysis

## Key Performance Indicators
- Total Customers: 10,000
- Churned Customers: 597
- Churn Rate: 5.97%
- Active MRR: 410K
- Churned MRR: 23K

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Excel
- CSV datasets

## Dataset
The project uses five datasets:
- Customers
- Churn
- Subscriptions
- Usage
- Support

1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Explore the four dashboard pages.
